# dotfiles

## Steps to bootstrap new computer

1. Install [Homebrew](https://brew.sh/)
2. Install [oh-my-zsh](https://ohmyz.sh/)
3. Install stow `brew install stow`
4. Install tmux `brew install tmux`
5. Install nvim `brew install nvim`
6. Install [nvm](https://nodejs.org/en/download/package-manager)
7. Install tmux plugin manager `git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm`
8. Install tmux plugins
9. Install oh-my-zsh plugins
10. run `stow zsh` and others
